KSW-VSA01 频谱仪上位机 · 界面复刻演示

一台 PySide6 桌面程序的界面完整搬进浏览器：面板、控件、默认值逐项照抄源码， 迹线由页内模拟器按真实 SCPI 报文格式收发——改 SPAN / RBW / 衰减，画面上真的会变。

界面按真实程序复刻 · 数据为模拟 无实机、无后端：分组、控件与取值范围取自源码 main_window.py， 迹线由页内 SCPI 模拟器按真实报文格式（ASCII 行 / IEEE488.2 二进制块）收发，不是写死的台词。 单独全屏打开 →
载入界面…

操作提示：端口填 15025 连上页内模拟器，点【应用参数】改频率 / SPAN / RBW / 衰减即见迹线响应； 【峰值标记】【通道功率】【诊断】【保存问题报告】均可点。详细对照关系见下节。

02

复刻对照/ Source Mapping

演示里的每一个面板都有源码出处，没有源码依据的控件一个也没放。

顶部连接栏
IP / 端口 / 连接 / 诊断 / 状态灯对应 _build_ui()
连接流程
TCP → *IDN? → 二进制传输 → 连续扫描 → 参数回填对应 _on_connect()
显示模式
频谱 / 时域 (零扫宽)，面板随模式感知对应 _switch_mode()
频率 / 带宽组
中心频率 · SPAN · RBW / VBW（带「自动」）对应 _build_control_panel()
幅度 / 扫描组
参考电平 · 衰减 · 扫描时间 · 扫描点数 · Y 轴自动缩放同上
操作组
应用参数 · 峰值标记 · 导出 CSV · 通道功率 · 仪器复位等同上
绘图区
pyqtgraph 外观复刻：网格、Trace1 配色、峰值散点与标注对应 _build_plot_panel()
通信日志 / 状态栏
时间戳 + 指令行；频谱 | 点数 | 范围 | 峰值实时刷新对应 log() / _on_data()
输入校验
中心频率非负、SPAN>0、SPAN 自动钳位并弹窗对应 _on_apply()
四步诊断
连通性 → 识别 → 参数查询 → 迹线读取，逐行留痕对应 _on_diag()
报文 / 信号层
IEEE488.2 二进制块解析；主峰 + 谱线 + 杂散 + 底噪模型对应 scpi_client / simulator
03

能力边界/ What This Demo Is Not

浏览器打不开 TCP 套接字，所以连上的不是仪器，是页面里的一个模拟器。

诚实声明
这是界面演示，不是测量结果。数值全部由页内模拟器按源码信号模型生成，不涉及任何真实设备。 为让 RBW / 衰减等参数「看得见反应」，演示补了几条源程序未实现的显示规律， 逐条列在 app/index.html 顶部注释；未列出的界面行为一律照源码实现。
真实程序
Python 3 · PySide6 · pyqtgraph · 单 exe 零依赖
通信
以太网 TCP，端口 5025（演示模拟器 15025），ASCII SCPI
本演示
单文件 HTML + canvas，无构建、无网络请求、无第三方库
版本
v1.2.1（窗口标题、日志与报告均沿用该版本号）
不复刻
日志落盘、崩溃钩子、os.startfile、系统信息采集
隐私
不含真实 IP、内网主机名、用户名、设备序列号与日志原文

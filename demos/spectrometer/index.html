KSW-VSA01 频谱仪上位机 · 界面复刻演示

一台 PySide6 桌面程序的界面被完整搬进浏览器：面板划分、控件文字、默认值、深色配色逐项照抄源码， 迹线与 SCPI 报文由页内模拟器按真实格式收发——改 SPAN / RBW / VBW / 衰减，画面上真的会变。

界面按真实程序复刻 · 数据为模拟 无实机、无后端：iframe 复刻的是 KSW-VSA01 频谱仪上位机 v1.2.1 的主窗口，分组、控件、 取值范围与配色取自 src/main_window.py；迹线由页内 SCPI 模拟器按 src/simulator.py 的信号模型生成，指令串按 src/scpi_client.py 的报文格式（ASCII 行 / IEEE488.2 二进制块）真实发出后再解析——不是写死的台词。 单独全屏打开 →
载入界面…

操作提示：点【应用参数】改中心频率 / SPAN / RBW / VBW / 衰减，迹线形状与底噪立即响应； 参考电平在源程序里只下发给仪器（Y 轴由 pyqtgraph 自动定标），故勾选「Y 轴自动缩放」时画面不变， 取消勾选后顶格栅线才锚到参考电平。点【峰值标记】在迹线真实最高点落标记； 切「时域模式 (零扫宽)」面板会自动收起 SPAN 与起止频率、禁用峰值与通道功率； 点【诊断】跑四步体检；【保存问题报告】把界面参数与通信日志打包成 txt 下载。 端口填 15025 即连上页内模拟器（等价于源程序的 python main.py --demo）， 填其他端口会走真实的连接失败分支并给出排查建议。

02

复刻对照/ Source Mapping

演示里的每一个面板都有源码出处，没有源码依据的控件一个也没放。

顶部连接栏
仪器 IP / 端口 / 连接 / 诊断 / 设备信息 / 帮助 / 状态灯对应 _build_ui()
连接流程
TCP 连接 → *IDN? 识别 → FORM:DATA REAL,32 → INIT:CONT ON → 参数回填对应 _on_connect()
显示模式
频谱模式 / 时域模式 (零扫宽)；模式感知面板对应 _switch_mode() / _apply_mode_ui()
频率组
中心频率 1 GHz、频宽 SPAN 100 MHz、起止频率（自动）双向联动对应 _build_control_panel()
带宽组
RBW / VBW 各带「自动」，默认 1 MHz同上
幅度组
参考电平 (dBm) = 0、衰减 (dB) = 10 带「自动」同上
扫描组
扫描时间（含橙色提示行）、扫描点数 101~100001 步进 500 默认 1001、连续扫描、Y 轴自动缩放同上
操作组
应用参数 / 自动调整 / 单次扫描 / 峰值标记 / 导出 CSV / 读取错误 / 通道功率 / 仪器复位 + 刷新率三档同上
绘图区
pyqtgraph 外观复刻：底 #10101a、网格、Trace1 图例 #00e5ff、峰值散点 #ff5252 与文字对应 _build_plot_panel()
配色与字体
深色样式表与 Microsoft YaHei UI 9pt对应 _apply_dark_theme() / main.py
底部通信日志
时间戳 + 指令行 → SWE:POIN 1001，含【保存问题报告】【打开日志】对应 log() / _save_report()
状态栏
频谱 | 1001 点 | 范围 9.5e+08 ~ 1.05e+09Hz | 峰值 -12.4 dBm对应 _on_data()
输入校验
中心频率非负、SPAN>0、起始频率不为负时 SPAN 自动钳位到 2×中心频率并弹窗对应 _on_apply()
四步诊断
TCP 连通性 → *IDN? → 六项参数查询 → 迹线读取，逐行留痕并出结论对应 _on_diag()
报文层
指令以 \n 结尾；迹线按 #<N><len><data> 小端 float32 解析，非 # 开头自动按 ASCII 逗号解析对应 scpi_client.py
信号模型
中心主峰 + ±0.28/0.32 SPAN 处的两个谱线 + 半中频杂散 + 底噪 -95+ATT*0.5对应 simulator.py
03

能力边界/ What This Demo Is Not

浏览器打不开 TCP 套接字，所以连上的不是仪器，是页面里的一个模拟器。

诚实声明
这是界面演示，不是测量结果。数值全部由页内 JavaScript 按 src/simulator.py 的模型生成，SCPI 指令串按源码格式合成后再由页面自己的解析器读回； 识别串里的序列号是模拟器占位符，不涉及任何真实设备。
为了让 RBW / VBW / 参考电平在画面上「看得见反应」，演示按真实频谱仪的规律补了几条 simulator.py 并未实现的模型（底噪随 RBW 平移、VBW 对相邻扫描做视频平滑、 关闭 Y 轴自动缩放后顶格栅线锚定参考电平）；逐条列在 app/index.html 顶部的注释块里，未列出的界面行为一律照源码实现。源程序自带的 78 项闭环测试 （test_closure.py）是 Python 测试套件，与界面无关，本演示不复刻。
真实程序
Python 3 · PySide6 · pyqtgraph · 单 exe 零依赖
通信
以太网 TCP，端口 5025（演示模拟器 15025），ASCII SCPI
本演示
单文件 HTML + canvas，无构建、无网络请求、无第三方库
版本
v1.2.1（窗口标题、日志与报告均沿用该版本号）
不复刻
日志落盘、崩溃钩子、os.startfile、系统信息采集
隐私
不含真实 IP、内网主机名、用户名、设备序列号与日志原文

硕士三年主要在做车载天线：紧凑型低剖面 5G MIMO 天线、集成定位与通信的多通道天线盒、 板端接口款天线盒、GNSS 有源天线。从跟企业对接需求、拆指标，到结构布局、板材选型、 陪加工厂抠公差、进暗室对着网络分析仪一版一版调——这条链上的每一步我都亲手做过。 对应的论文、专利和实测数据，在站内各项目页里都能查到。

我本科是搞嵌入式的，写过智能车和电赛的代码、拿过几个省奖，所以仿真等不起的时候， 第一反应是自己写工具：用 Python 驱动 HFSS 自动改参数、跑优化（PSO、贝叶斯）， 再拿贝叶斯神经网络做代理模型、配主动学习，把全波仿真的次数往下压。 最近在试把物理先验塞进强化学习，这个方向还在研，进展放在 P-04。

现在在上海利正卫星做整星与单机的 EMC、磁、力学、真空热试验，也参与实验室 CNAS 认可 和试验产线建设。听起来换了赛道，其实是同一件事的另一端：以前我关心"这根天线会不会 干扰别人"，现在我关心"这颗星在振动、真空、高低温里，还能不能正常工作"。

S-01 · 一个优化闭环必须由四件事同时成立

很多人把"算法优化 HFSS"理解成套一个 PSO。真正跑起来才发现，难点不在算法，在闭环本身： 参数要能写进模型而不破坏几何拓扑；求解要能在无人值守时稳定收敛到解；结果要能按 目标函数而不是按 S11 单点被评价；失败的一次发散不能把整轮寻优带走。 所以这套东西的四个组件是绑在一起设计的： 几何参数化层（变量边界与合法性校验，越界的个体在进求解器之前就被拒）、 求解调度层（多 HFSS 实例并行，把一次评估的墙钟时间摊薄）、 目标与约束层（增益、带宽、隔离度、轴比这类互相冲突的目标显式建模， 因此它天然是多目标问题，输出 Pareto 前沿而不是"一个最优解"）、 算法层（MOPSO / NSGA-II / NSGA-III / CMA-ES / MOEA/D / RVEA / AGE-MOEA2 可换， 是为了在同一课题上做横向对比，而不是为了堆名词）。

代理模型是第二层关键。全波仿真是分钟到小时级的代价，群体法一代上百个体、几十代就是上万次求解， 直接寻优在工程预算上不成立。所以用贝叶斯优化 + 高斯过程代理（GPFlow SVG-P，Matérn-5/2 核） 去"猜"哪些参数点值得真跑，靠预测不确定性做主动采样：不确定度大的地方才值得花钱。 再往后是我在推进的方向 —— 把物理先验嵌进强化学习的架构里， 避免智能体把预算浪费在物理上根本不可行的区域。

S-02 · 上位机的真正工作量在"连不上的时候"

控制一台频谱仪，协议本身不难：以太网 TCP 上跑 ASCII SCPI， 不是 VISA / GPIB —— 这个选择去掉了驱动栈依赖，也把责任全揽到了自己这边。 于是真正花时间的是那些"仪器不会告诉你的失败"： 端口通但指令无响应、响应被分包粘在一起来回解析、参考电平与衰减配合不当导致的过载或噪底过高、 扫描点数与 RBW/VBW 组合出的测量时间被误判成"卡死"。 所以界面上看起来"多余"的三块，其实是血泪换来的：四步连接诊断（把可达性、端口、 身份识别、指令回环拆开逐层判）、一键问题报告导出、全局异常钩子留痕。

显示侧用 pyqtgraph 而不是 QtCharts，是因为要在实时扫频下保持流畅； 频谱模式与零扫宽时域模式共用一套参数面板但走不同的取数节奏。 功能上覆盖了中心频率 / Span / RBW / VBW / 参考电平 / 衰减 / 扫描点数的远端控制， 峰值标记、通道功率（CPOW）、SENS:ADJ:ALL 自动调整、 *RST、以及迹线的 CSV 导出以便进 Origin 出图 —— 最后这条是给我自己用的：测完要写报告，能直接拿到数很重要。 另外内置了模拟器，没有仪器也能演示与回归测试；配套的 78 项闭环测试就是靠它跑的。

S-03 · 教学 3D 的难点是"讲清楚"而不是"画漂亮"

霍尔推力器的科普内容大多错在两处：把径向磁场画成轴向或偶极， 以及把电子运动画成"被电场拉着走"而忽略霍尔漂移。 这个页面的取舍是：几何与量级按 SPT-100 一类器件搭， 数值全部取自公开文献（Goebel & Katz 的《Hall Thrusters》与 Morozov 的磁透镜工作）， 然后让电压、磁场、流量三个滑杆真的改变粒子行为 —— 因为只调数字不联动图像的教学页，看了等于没看。

可点击拆解的部件包括陶瓷放电通道、内 / 外磁极与励磁线圈与磁轭、阳极、空心阴极与航天器底座； 粒子层分别仿真电子的霍尔漂移与回旋、氙原子的电离级联、离子在通道内的加速与羽流膨胀、 以及中和阴极提供的束流中和。剖切面随视角旋转，配合左侧四幅 2D 辅助曲线 （电位、磁场强度、电子能量、离子速度分布）形成"三维看结构、二维看量"的读法。

站内三个演示均为前端呈现，无后端：S-01 以 mock 垫片提供模拟接口数据， S-02 的界面按 src 源码复刻并生成模拟迹线，S-03 为原始静态页面（需联网加载 Three.js CDN）。 工程本体不在仓库内，GitHub Pages 有容量限制，站内只承载界面与说明。
